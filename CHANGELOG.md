# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-09-16

### Added

- Hybrid vector and BM25 retrieval with Reciprocal Rank Fusion.
- Optional CrossEncoder reranking.
- PDF, DOCX, Markdown, TXT, and CSV ingestion.
- Persistent FAISS index and SQLite conversation history.
- Citation-aware question answering with retrieval fallback.
- FastAPI service with optional API key authentication.
- Streamlit user interface.
- Retrieval evaluation metrics and sample dataset.
- Docker, Docker Compose, CI workflow, and unit tests.
